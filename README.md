# ArcaeaRhythmAnalysis
Arcaea节奏解析源代码<br>使用方法：<br>1.将谱面文件夹放入chart文件夹中<br>2.在config.txt中设置参数（包括谱面文件夹名称、难度等信息，具体参见config.txt）<br>3.用命令行工具依次运行四个py文件，并做相应处理<br>运行方式：在命令行中输入“python {文件夹路径}\x.py”<br>4.在运行4.py后，浏览器会自动打开节奏解析预览，此时需要点击一次浏览器界面（否则不会播放音乐）

1.py：连续蛇/碎蛇清理工具<br>将前面连接其他arc的后续arc或快于150bpm16分的碎arc调整为黑线，并生成0.aff（ftr）或1.aff（byd/etr）<br>为防止调整错误，较慢的碎arc不会自动调整为黑线，需在生成的谱面中自行调整为黑线<br>若需要展示arc的拐点节奏，请将对应时间点开始的任意一条arc改为绿arc<br>由于谱面经常会写timing特效或将流速固定，在使用该工具后，请自行检查timing_{chart}.txt并修改其中的timing为歌曲实际timing（尤其注意节拍相关问题）

2.py：节奏数组生成工具<br>生成节奏数组，由于精度问题或毫秒采音问题，生成时可能出现问题，需要手动在rhythm_{chart}.txt调整<br> 如果确信谱面中出现了11连音等未预设的音符，请在代码中的allowed_denominators手动添加细分种类

3.py：生成图形svg<br>按照节奏数组中的节奏生成图形svg

4.py：生成节奏解析预览和按键音<br>按键音生成较慢，需要等待<br>默认宽度为1280px，打开后应该能发现界面右侧有一个">"形对齐边缘，如果未发现或未对齐，请调整config中的width参数

文件夹中提供了《多次元宇宙融合論》的ETR节奏解析预览。为避免版权问题，未提供原始谱面和音乐音频等版权内容
